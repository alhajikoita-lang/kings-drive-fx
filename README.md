# KINGS DRIVE FX

Tesla friendly browser prototype with GPS speed tracking, simulated RPM and gearing, five selectable profiles, and manual throttle testing.

## Test
Open the GitHub Pages URL over HTTPS. While parked, allow location access and press **START DRIVE**. Use **MANUAL TEST** to test the interface without GPS.

## Audio
The reactive audio layer will use original or properly licensed sound assets. No proprietary EV Sound FX audio is included.

## Safety
Set up and select sounds while parked. This project does not interact with or replace Tesla pedestrian warning hardware.
